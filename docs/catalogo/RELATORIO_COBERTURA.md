## Critério de publicação

Todos os registros do checkpoint são exportados para a busca pública com estado de conferência visível. O uso na calculadora exige inventarioValidado=true e usavelNaCalculadora=true; nenhum registro com inventário pendente é enviado para o cálculo. O enriquecimento permanece separado e ainda não foi validado neste checkpoint.
